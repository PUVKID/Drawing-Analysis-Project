# 현재 공개 파일과 차수별 변화

| 차수·위치 | 현재 파일 | 추가 경로 | 내용 변경 | 이전에만 존재 |
|---|---:|---:|---:|---:|
| `기본` | 17 | 17 | 0 | 0 |

- 현재 연구 파일 합계: **17개**. 루트 `README.md`, `CHANGELOG.md`, `.gitignore`와 `docs/` 관리 문서는 집계에서 제외합니다.
- 경로에서 처음 만나는 숫자 차수 또는 `최종`으로 묶습니다. 같은 상위 경로의 숫자 차수끼리만 경로·SHA-256을 비교합니다. `기본`과 `최종`은 독립 묶음이므로 다른 차수와 자동으로 의미 대응시키지 않습니다.
- 추가·변경·이전 경로 수는 파일 비교 결과입니다. 기능 변경은 [README의 구체적인 구현·차수 설명](../README.md)을 함께 확인하세요.
- 제외된 원데이터·모델·인증정보와 관리 문서는 이 표의 대상이 아닙니다.

## 예시 이미지의 집계 범위

`assets/previews/`와 `assets/overview.png`는 설명용 보관 자료이며 위 원본 파일 집계에서 제외합니다. 현재 소개 화면은 이모지·텍스트와 비교표로 구성합니다.

## 🧭 자료별 의미와 근거

| 자료 | 실제 경로 | 목적과 내용 | 근거 |

| 자료와 안내 | 자료의 성격 | 구체적인 차이와 연결 |
|---|---|---|
| [기본](versions/stage-1.md) | 앱 코드 | 공개 코드에 확인되는 숫자 차수는 없습니다. 별도 보관된 코드의 역할을 안내하며 출시 순서나 최종 확정을 만들지 않습니다. |
